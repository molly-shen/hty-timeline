# 图片目录说明

这个目录用于存放时间线事件的相关图片。

## 图片命名规则

图片按照以下格式命名：
- `YYYY-MM-DD-事件描述.jpg`
- 例如：`2021-04-30-concert.jpg`

## 图片类型

支持的图片格式：
- JPG/JPEG
- PNG
- GIF

## 图片尺寸建议

- 推荐尺寸：800x600 像素
- 最小尺寸：400x300 像素
- 最大文件大小：2MB

## 图片内容

每个事件可以包含以下类型的图片：
- 活动现场照片
- 社交媒体截图
- 演出海报
- 采访截图
- 直播截图
- 其他相关图片

## 占位符图片

如果暂时没有实际图片，可以使用占位符图片：
- 尺寸：400x300 像素
- 背景色：#f0f0f0
- 文字："图片加载中..."

## 注意事项

1. 确保图片版权合规
2. 图片质量要清晰
3. 文件大小要适中
4. 图片内容要与事件相关
